## 📖 About the Work

*Lisonut-tayr* (*لسان‌الطیر*) is Alisher Navoi's masterpiece — a Sufi allegorical poem in which birds journey to find the mythical Simurgh. The PLT analysis reveals:

- **Semantic invariants** across 600 years of Uzbek textual tradition
- **Fractal patterns** in Navoi's symbolic system
- **Cross-linguistic mapping** — Chagatai ↔ Modern Uzbek ↔ Persian ↔ Russian

## 🔬 PLT Methodology

The Post-Lingua Trace (PLT) framework identifies meaning structures that persist across:
1. Historical linguistic shifts (Chagatai → Modern Uzbek)
2. Script changes (Arabic → Cyrillic → Latin)
3. Translation traditions (Uzbek → Russian → English)
