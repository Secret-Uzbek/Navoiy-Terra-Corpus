> the wider Terra / FMP ecosystem.

## Layer role

This repository is a human-facing literary corpus branch.

It should hold:

- readable Navoiy-centered research materials;
- literary, semantic, and civilizational analysis;
- branch-level publications and evidence surfaces;
- comparative and visual outputs that help people enter the corpus.

It should not become:

- a generic theory hub;
- a donor governance repository;
- a broken symbolic shell with no human reading path;
- an undifferentiated archive sink.

## Ecosystem position

- `FMP-CENTRAL-REPO` — central public hub
- `Theory-of-fractal-metascience-paradigm` — theory layer
- `babur-terra-codex` — historical continuity branch
- `ziyarat-terra-corpus` — sacred discourse branch
- `women-made-central-asia` — human-facing civilizational branch
- `terra-legal` — donor governance and standards

## Operating rule

This repository must remain readable for humans first.

Its role is to open a literary-civilizational branch of the ecosystem, not to
replicate every other Terra layer inside one repository.
